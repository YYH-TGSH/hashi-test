# Phase D 混合大亂鬥賽程引擎 — 設計稿（2026-10-16）

> 狀態：設計稿，**等雙機複測 verdict（commit 36b9cf7 的三個修正點）通過後**再給使用者過目、動工。
> 本稿只用到現有架構＋現有訊息，不改遊戲核心玩法。

## 使用者已拍板的賽制（2026-10-16，不再問）

- 打滿 **5 局**，不提前結束；5 局加總最高分者為總冠軍。
- 每局名次計分：第 1 名 **10**、第 2 名 **7**、第 3 名 **5**、第 4 名 **3**、第 5 名 **2**（2 人對戰時就是 10/7）。
- 未完成者：以該局結束時（全員完成或時間到）的**進度 %** 排序定名次。
- 同分 tiebreak：先比**冠軍局數**（拿第 1 名的局數多者勝），仍同分則**加賽 1 局數橋**決勝。
- 輪替：交替為預設；房主可改隨機。房主設每款的難度／尺寸。
- 每局可設時間上限（例 5 分鐘），時間到未完成者以進度 % 定名次。

## 架構：殼端 `PlatTourn` 控制器（房主權威）

沿用現有信任模型（房主 relay 上帝視角、廣播 launch/return），賽程狀態由房主殼計算、廣播，來賓只渲染。

### 新增 `{__plat}` 訊息（與遊戲訊息同連線多工，沿用現有信封）

| kind | 方向 | 內容 |
|---|---|---|
| `tourn-setup` | 房主→全員 | 賽程表：`rounds: [{game:'sudoku'|'hashi', sizeId, diffId}…]`、每局秒數 `roundSecs`、起始時間 |
| `tourn-score` | 房主→全員 | 該局名次＋每局得分＋累計總分：`{round, placements:[{pid,name,rank,pts}], totals:{pid:pts}}` |
| `tourn-end` | 房主→全員 | 總冠軍：`{champion:{pid,name}, totals, tiebreak}` |

### 每局流程

1. **開賽設定（大廳）**：房主開「🏆 混合大亂鬥」設定頁 → 選出局順序（預設 數獨→數橋→數獨→數橋→數獨；另有 數橋先 / 隨機）、數獨尺寸＋難度、數橋難度、每局時間上限（預設 5 分鐘，可選 3/5/8/10/無限）→ 廣播 `tourn-setup`。
2. **自動開局**：房主按「開打」→ 殼呼叫現有 `doLaunch(game,'brawl')`（`shell.js:409`），`sess` 擴充 `tourn:{round,total,sizeId,diffId}`；來賓收到 `kind:'launch'`（`shell.js:310`）同樣進入。**遊戲端小改**：兩款 `__PLAT_HOOKS` 的 `enter`（數獨 `sudoku-site/js/app.js:2014`、數橋 `hashi-site/js/app.js:1978`）在 `sess.tourn` 存在時直接套用尺寸／難度預設、跳過賽前設定畫面。
3. **殼端觀測（不動遊戲協定）**：遊戲訊息都經殼的 VirtualConn 層（`shell.js:561`），殼可嗅探現有訊息做即時計分——
   - 數獨大亂鬥：`GHOST_SOLVED`（進度）、`GHOST_I_WON`／`GHOST_WINNER`（完賽）——在現行 `js/sudoku/app.compiled.js` 實測存在；
   - 數橋大亂鬥：`RACE_PROGRESS`（進度）、`RACE_FINISH`（完賽）——在現行 `js/hashi/app.compiled.js` 實測存在。
   - 殼維護 `progress[pid]`（最後已知進度 %）與 `finishOrder[]`（完賽順序）。
4. **結算**：全員完賽 **或** 時間到 → 房主依「完賽順序 → 未完賽按進度 %」定名次 → 10/7/5/3/2 計分 → 廣播 `tourn-score` → 全員自動離開遊戲（現有 `exitGameHook`＋`return` 流程，`shell.js:418`）→ 殼顯示**積分榜**（本局名次＋累計總分＋下一局預告）。
5. **下一局**：房主在積分榜按「▶ 下一局：數橋大亂鬥」→ 回到步驟 2。5 局打完 → 廣播 `tourn-end` → **總冠軍畫面**（🏆＋總分表＋tiebreak 說明）→ 回大廳。

### 時間到的處理（MVP 簡化）

時間到時不要求遊戲內凍結：房主殼直接走現有離局流程（`doReturnToLobby` 廣播 `return`），名次按嗅探到的最後進度 % 計算。這是已知簡化，v1 可接受；若使用者嫌結算畫面跳得太突然，再加遊戲端 `TOURN_TIMEUP` 凍結訊息。

### 道具（MVP：各玩各的）

混合賽每局沿用**該遊戲自己的道具**（數獨局用數獨的炸彈／掃把／禮物，數橋局用五件套）。跨遊戲道具對照（水球→霧化島嶼等）是藍圖 Phase 4 的題目，本階段不做——使用者若問起再排。

### 邊界情況（沿用現有語義，不新增機制）

- 對局中有人離開 → session 結束 → 賽程中止（同今日行為）。
- 中途加入者 → 在大廳等下一局（同今日行為）。
- 房主斷線 → 全員回平台首頁（同今日行為；平台模式本來就停用數獨房主接管）。
